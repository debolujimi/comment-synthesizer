# Project Pitch

Comment Synthesizer is a lightweight response-generation tool for Eskom service and outage communication. It turns customer messages about loadshedding, outages, billing issues, and power shortages into structured, helpful Eskom-style responses.

The project is designed to be practical and extensible: it starts as a desktop app, exposes a web API, and can be reused by mobile clients. Its core strength is the combination of explainable rule-based matching and a clean, reusable backend.

This makes it a strong prototype for customer-service automation, communication support, and rapid response tooling in South African utility contexts.
